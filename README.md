## 🌟 Overview

**FOOTORIA** is an interactive, responsive web experience dedicated to the world's most prestigious football tournament: the **FIFA World Cup™**. From its inception in Uruguay in 1930 to the groundbreaking 48-team tournament in 2026, Footoria captures the legacy, drama, and iconic icons of the beautiful game.

🌐 **Live Website:** [https://ribeka47.github.io/FOOTORIA/](https://ribeka47.github.io/FOOTORIA/)

---

## ✨ Features

- **🏆 Hero Section:** Cinematic visual showcase with custom branding and quick-action navigation.
- **📜 Heritage & Quick Facts:** Key tournament milestones and quick statistics (inaugural year, frequency, expansion, and top title holders).
- **🌎 2026 Host Countries & Stadiums:** Comprehensive breakdown of host nations (🇨🇦 Canada, 🇲🇽 Mexico, 🇺🇸 United States), stadiums, cities, and match allocation.
- **🎭 Unexpected & Iconic Moments:** Curated stories of historic upsets, dramatic finishes, and unforgettable football lore.
- **👑 Hall of Fame (Titles & Legends):** Dedicated spotlight on the game's greatest figures:
  - **Pelé** (Brazil) — The only 3-time World Cup Champion (1958, 1962, 1970).
  - **Diego Maradona** (Argentina) — The 1986 masterclass and Goal of the Century.
  - **Lionel Messi** (Argentina) — The 2022 fairytale triumph in Qatar.
  - **Cristiano Ronaldo** (Portugal) — The record scorer across 5 consecutive World Cups (2006–2022).
- **📱 Fully Responsive Design:** Tailored for seamless viewing across desktops, laptops, tablets, and mobile devices.

## 🛠️ Built With

- **HTML5:** Semantic markup structure with accessibility standards.
- **CSS3:** Modern CSS with custom properties (CSS variables), Grid, Flexbox, backdrop blur filters, and smooth micro-animations.
- **Google Fonts:** `Cinzel`, `Poppins`, and `Noto Sans` for typography.

## 🚀 Getting Started Locally

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ribeka47/FOOTORIA.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd FOOTORIA
   ```

3. **Open in browser:**
   - Double-click `index.html` to open it in your default browser, or
   - Use the VS Code / IDE **Live Server** extension.
